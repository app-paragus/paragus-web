# paragus-web

The paragus.xyz marketing site — waitlist landing page for Paragus.

Stack: Next.js 16 + Tailwind CSS v4, Satoshi (self-hosted), static output.
Design source: `Paragus/design/landing/` (the design canvas artboards).

```bash
pnpm install   # or npm install
npm run dev    # http://localhost:3006
```

The waitlist form is visual-only for now (TODO: wire a backend before launch).
